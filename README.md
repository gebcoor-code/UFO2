# НЛО-2. Дьяволы бездны - EGA edition для Turbo 2+ (CP/M) и NedoOS

Порт игры «НЛО-2. Дьяволы бездны» (с) 1996 Слава Медноногов с ZX Spectrum 128 на Turbo 2+ под CP/M: 320x200,
16 цветов, мышь. Отдельная сборка - для NedoOS (ZX Evo BaseConf). ae485 (coor@mail.ru), 2026 (при помощи ИИ).

Текущие версии: CP/M **0.67.13**, NedoOS **n0.12**. Готовые сборки для NedoOS - в
[Releases](https://github.com/gebcoor-code/UFO2/releases) (последняя всегда:
`https://github.com/gebcoor-code/UFO2/releases/latest/download/ufo2-nedoos.zip`).

## Что где лежит

| папка / файл | что это |
|---|---|
| `port/` | код порта (sjasmplus): `zxl.asm` - UFO2.COM, `nedo.asm` - слой NedoOS |
| `build/` | сборка: `build.sh` (CP/M), `nedo.sh` (NedoOS), конвертеры картинок и данных, `build/data` - данные |
| `UFO2SRC/` | исходники оригинальной игры (публичный релиз 2001 г.) |
| `tools/` | стенд ATM CP/M (`atmsim.py`), проверки и анализаторы |
| `tools-graph/` | инструменты для работы с графикой |
| `test/` | сценарии стенда; `test/nedo/emu` - проверка NedoOS-сборки в эмуляторе |
| `fliptest/` | тест переключения экранов |
| `about.txt`, `about_nedo.txt` | ABOUT.TXT для игрока (CP/M и NedoOS) |
| `DEPLOY.md` | подробно о сборке и составе файлов |

## Сборка

Нужны Python 3 и sjasmplus (путь можно задать переменной `SJASM`, по умолчанию `sjasmplus` из PATH).

```
sh build/build.sh     # CP/M: build/out/
sh build/nedo.sh      # NedoOS: build/out_nedo/dist/ (UFO2.COM и папка ufo2)
```

Подробно - в [DEPLOY.md](DEPLOY.md).

## NedoOS (ZX Evo BaseConf)

Сборка `build/nedo.sh` (вызывается и из `build.sh`): те же исходники с `-DNEDOOS`, результат - `build/out_nedo/dist/`:
`UFO2.COM` и рядом с ним папка `ufo2` со всеми остальными файлами (их кладут на карту как есть, например `M:/UFO2.COM`
и `M:/ufo2/`; запуск из NC в папке с `UFO2.COM`: Enter на нём или команда `ufo2`, отладочный режим - команда
`ufo2 debug` или `ufo2 debug xNN`). ABOUT.TXT этой сборки - из `about_nedo.txt` (свой текст для NedoOS: при
изменениях держать его в актуальном виде вместе с `about.txt`).
CP/M-сборка без флага не меняется (UFO2.COM, UFO2.DAT, UFO2.MNU - как без NedoOS-правок; с n0.5 - код 0.67.8).

Устройство (port/nedo.asm, nedo_h.inc):
- страницы: у ядра берутся именно те, чьи номера пишет CP/M-код (#7F - p, физические 128 + p на Evo), поэтому вся
  арифметика страниц осталась; экраны - настоящие (#FF - p для 1, 3, 5, 7: PS1..PS7, SCRV); порты окон #x7F7
  (P_W1..P_W3);
- ядро после прерывания и вызова восстанавливает окна из curpg*: обработчик (цепочка на #0038) и обёртка BDOS
  записывают их из обратного чтения окон Evo (#01BE..#03BE); у обработчика свой стек - на стеке игры только PC;
- IM 1: после ядра - вектор n_vec (место IM2-вектора CP/M: LD_INT, меню, затем #3D3D); IM 2 игры (l_start)
  заменяется на IM 1;
- нижние #80 байт не трогаются (кроме 3 байт #0038, возвращаются при выходе); массивы bsync..dlin и int_f.. - на
  месте таблицы IM2 (#3E00..);
- BDOS (FCB) - через n_bdos в странице 3 (#F000): 9 / 2 - текст, 6 - OS_GETKEY, ESC M0 - EGA (OS_SETGFX с
  сохранением страниц экрана, OS_SETPAL); vmode - OS_SETGFX, #7FFD - OS_SETSCREEN; файлы на карте дополнены до
  128 байт (FCB-чтение NedoOS);
- файлы игры: при старте CHDIR в папку `ufo2` рядом с UFO2.COM (путь из имени программы в командной строке +
  `ufo2`; нет такой папки - текущая); UFO2.ENC - только оттуда (CP/M перебирала диски через BIOS);
- выход (меню "Выход в DOS"): запись UFO2.SAV, тишина AY, QUIT - назад в NC;
- смена фокуса: обработчик каждое прерывание смотрит user_scr0_low (#FE - экран наш); фокус ушёл - игра стоит
  (состояние её прерывания сохранено, возврат ядра - в цикл HALT в странице 3, AY молчит); фокус вернулся - палитра
  (последняя, что ставила игра: pal_std, mm_pal, xp_rmp пишут её копию в n_pal) отдаётся ядру, игра продолжается;
  пока фокуса нет, игра не тратит время (OS_YIELD);
- меню 3, 4 (инструкция, ABOUT.TXT): UFO2DOC.OVL - тот же UFO2DOC.COM (SEADOC), подготовленный build/mkdocovl.py
  (расшифрован, BDOS - n_bdos, BIOS - таблица n_doc на #F800, страницы экрана - настоящие, стеки выше текста);
  n_doc кладёт его на #0100 вместо кода игры (W0 #0100..#3FFF - в страницу 44, W1 / W2 - страницы 45, 46: до
  загрузки игры они свободны), выход (ESC / конец текста) - всё назад, снова меню;
- меню 1 (введение): как на CP/M (своё IM 2), режим ZX ставится и в порт (ядро ставит его только по своему
  прерыванию); банк 5 - настоящая страница экрана.
